# Moment-SOS Hierarchy and Polynomial Relaxations (`moment`)

The `moment` module implements the Lasserre / Moment-Sum-of-Squares (Moment-SOS) hierarchy for polynomial optimization and Boolean satisfiability (SAT / 3-SAT) semidefinite relaxations.

---

## 1. Mathematical Foundations

### The Truncated Moment Matrix

Let $x = (x_1, \dots, x_n)$ be a vector of indeterminates. Let $\mathbf{v}_d(x)$ denote the vector of all monomials of degree at most $d$. The moment matrix of degree $d$, denoted $M_d(y)$, is an $N \times N$ symmetric matrix defined by:

$$[M_d(y)]_{\alpha, \beta} = y_{\alpha + \beta}$$

where $\alpha, \beta \in \mathbb{N}^n$ are multi-indices with $|\alpha|, |\beta| \le d$, and $y_\gamma = \mathbb{E}[x^\gamma]$ is the pseudo-moment of monomial $x^\gamma$.

### Boolean Quotient Reductions

For discrete optimization problems over Boolean variables, monomials are reduced modulo the algebraic ideal of the domain:

1. **Zero-One Domain ($\{0, 1\}^n$)**:
   Ideals generated by $x_i^2 - x_i = 0$. Every power $x_i^k$ ($k \ge 1$) reduces canonically to $x_i$:
   $$x_i^k \equiv x_i \pmod{x_i^2 - x_i}$$
2. **Plus-Minus Domain ($\{-1, +1\}^n$)**:
   Ideals generated by $x_i^2 - 1 = 0$. Powers reduce via parity:
   $$x_i^k \equiv x_i^{k \bmod 2} \pmod{x_i^2 - 1}$$

### Degree-Reverse-Lexicographic (DegRevLex) Ordering

Monomials within `MonomialBasis` are sorted using canonical graded reverse lexicographic order:
1. Total degree $|\alpha| = \sum \alpha_i$ (ascending).
2. For equal degrees, compare exponents from the last variable $x_n$ backwards to $x_1$; the monomial with the smaller exponent comes first.

## 2. CNF and 3-SAT Polynomial Encoding

A CNF clause is a disjunction of literals $C = (\ell_1 \lor \dots \lor \ell_k)$. In the $\{0, 1\}$ Boolean domain, each literal is mapped to an error indicator $e_i$:

$$e_i = \begin{cases} 1 - x_v & \text{if } \ell_i = x_v \text{ (positive literal)} \\ x_v & \text{if } \ell_i = \neg x_v \text{ (negated literal)} \end{cases}$$

The clause is violated if and only if every literal evaluates to false ($e_1 = 1, \dots, e_k = 1$). Hence, the clause is satisfied if and only if the violation polynomial vanishes:

$$P_C(x) = \prod_{i=1}^k e_i = 0$$

### Degree Requirements and Invariants

To enforce the constraint $\mathbb{E}[P_C(x)] = 0$ on the moment matrix $M_d(y)$, the maximum degree of $P_C(x)$ cannot exceed the representable moments $2d$. If $k > 2d$, `build_moment_sdp_relaxation` returns:

```rust
Err(SciError::InvalidParameter("relaxation degree d is insufficient to represent clause polynomial of degree k"))
```

## 3. DIMACS CNF Parser and Writer

The `CnfFormula` struct includes strict validation for standard DIMACS CNF format (`.cnf`):

```rust
use scies_math_th::moment::sat_encoding::CnfFormula;

let dimacs = r#"c 3-SAT Example
p cnf 3 2
1 2 3 0
-1 2 -3 0
"#;

let formula = CnfFormula::from_dimacs(dimacs)?;
assert_eq!(formula.num_vars(), 3);
assert_eq!(formula.num_clauses(), 2);

// Re-serialize
let serialized = formula.to_dimacs();
```

## 4. SDPA Sparse Format I/O (`.dat-s`)

The SDPA sparse format is the universal standard for benchmarking semidefinite programs across solvers (such as SDPA, SeDuMi, and Mosek).

`export_sdpa_sparse` and `import_sdpa_sparse` provide serialization for single-block semidefinite programs:

```rust
use scies_math_th::moment::sdpa_io::{export_sdpa_sparse, import_sdpa_sparse};
use scies_math_th::sdp::SdpProblem;

// Export
let sdpa_text = export_sdpa_sparse(&sdp_problem, "Benchmark Problem")?;

// Import with validation
let reloaded_problem = import_sdpa_sparse(&sdpa_text)?;
```

### SDPA Parser Invariants
- Enforces single semidefinite block partition (`nblocks = 1`). Multi-block instances are rejected with `SciError::UnsupportedFormat`.
- Every entry line must have exactly 5 tokens: `<mat> <block> <row> <col> <val>`.
- Matrix indices ($0 \le \text{mat} \le m$) and 1-based block row/col coordinates are strictly checked.
- Non-finite tokens (NaN / Inf) are rejected with `SciError::ParseError`.

## 5. End-to-End Relaxation Example

```rust
use scies_math_th::moment::sat_encoding::{Clause, CnfFormula, Literal};
use scies_math_th::sdp::SdpSolverConfig;

fn main() -> Result<(), Box<dyn std::error::Error>> {
    let formula = CnfFormula::new(
        3,
        vec![
            Clause::new(vec![Literal::positive(0), Literal::positive(1), Literal::positive(2)]),
            Clause::new(vec![Literal::negative(0), Literal::positive(1), Literal::negative(2)]),
        ],
    );

    // Degree-2 Moment Relaxation (tracks moments up to degree 4)
    let (sdp, report) = formula.build_moment_sdp_relaxation_with_report(2)?;

    println!("Variables:            {}", report.num_variables);
    println!("Relaxation Order:     {}", report.relaxation_degree);
    println!("Moment Matrix Dim:    {} x {}", report.basis_size, report.basis_size);
    println!("Total Moments:        {}", report.num_moments);
    println!("Equality Constraints: {}", report.num_generated_constraints);

    // Solve using ADMM
    let config = SdpSolverConfig::default();
    let solution = sdp.solve(&config)?;
    println!("Solver status: {:?}", solution.status);

    Ok(())
}
```
