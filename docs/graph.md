# `graph` Module Documentation

Graph theory and network analysis.

## Overview

This module provides algorithms for pathfinding, network centrality, and spanning trees.

## Features
- **Shortest Path**: Dijkstra, A*, Bellman-Ford
- **Minimum Spanning Tree**: Prim's Algorithm
- **Network Analysis**: PageRank

## Notes

- Use this module for graph-shaped scientific, network, or dependency data.
- Pathfinding routines are most useful when paired with explicit node and edge models.
