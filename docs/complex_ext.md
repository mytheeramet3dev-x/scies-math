# `complex_ext` Module Documentation

Extended complex analysis: conformal maps, Laurent series, residues, polynomial roots,
complex integration, Blaschke products, multi-branch logarithm.

## Overview

This module extends the core complex-number type with analysis-oriented helpers used in numerical methods and signal-adjacent workflows.

All functions use [`crate::complex::C64`].

## Topics

- conformal maps
- Laurent series
- residues
- polynomial roots
- complex integration
- Blaschke products
- multi-branch logarithm

## Notes

- Use this module when the core `complex` APIs are not enough for analysis workflows.
- The focus is practical numerical support rather than symbolic manipulation.
