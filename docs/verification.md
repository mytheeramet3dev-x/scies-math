# Mathematical Verification and Lean 4 Bridge (`verification`)

The `verification` module provides proof provenance tracking, derivation audit trees, and an automated code generation bridge targeting the Lean 4 proof assistant and its Mathlib library.

---

## 1. Proof Provenance and Derivation Trees

When performing symbolic manipulations, scientific compliance often requires a traceable audit log showing how each expression was obtained from initial assumptions.

### `DerivationTree`
A directed acyclic graph (DAG) where each node represents a mathematical statement and records:
- **Premises**: Pointers to antecedent steps.
- **Rule / Justification**: The algebraic rule applied (e.g. `AlgebraicSimplification`, `LinearCombination`, `Positivity`, `Hypothesis`).
- **Conclusion**: The resulting symbolic expression [`Expr`].

---

## 2. Lean 4 / Mathlib4 Export Bridge (`lean_export`)

Translates symbolic ASTs into syntactically valid Lean 4 theorem declarations:

```rust
pub fn export_lean4_theorem(
    theorem_name: &str,
    hypotheses: &[(&str, &str)],
    conclusion: &str,
    proof_tactic: Option<&str>,
) -> String
```

### Generated Provenance Header
Every generated Lean file includes an explicit notice identifying the generating crate and clarifying that the file is an unverified skeleton until certified by the Lean 4 kernel:

```lean
/-!
  Generated by scies-math-th (v0.3.0)
  Status: Generated theorem skeleton (requires verification by Lean 4 kernel)
-/

import Mathlib

theorem pythagorean_identity (θ : ℝ) : (Real.sin θ) ^ 2 + (Real.cos θ) ^ 2 = 1 := by
  ring
```

---

## 3. Code Example

```rust
use scies_math_th::symbolic::Expr;
use scies_math_th::verification::lean_export::{export_lean4_theorem, expr_to_lean};

fn main() {
    let x = Expr::sym("x");
    let poly = Expr::Add(vec![
        Expr::Pow(Box::new(x), Box::new(Expr::int(2))),
        Expr::int(4),
    ]);

    println!("Lean representation: {}", expr_to_lean(&poly)); // ((x ^ 2) + 4)

    let lean_code = export_lean4_theorem(
        "poly_strictly_positive",
        &[("x", "ℝ")],
        "x ^ 2 + 4 > 0",
        Some("positivity"),
    );

    println!("{}", lean_code);
}
```
