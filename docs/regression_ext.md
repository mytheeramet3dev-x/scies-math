# `regression_ext` Module Documentation

Extended regression & classification: Elastic Net, Softmax, Naive Bayes,
k-NN, Decision Tree, metrics (precision/recall/F1/AUC), cross-val.

## Overview

This module extends the base regression layer into broader predictive modeling and evaluation workflows.

## Notes

- Use this module when you need classification helpers alongside regression routines.
- Metrics and cross-validation live here to keep the core regression module focused.
