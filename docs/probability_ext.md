# `probability_ext` Module Documentation

Extended probability: multivariate distributions, information theory,
extreme value, Bayesian conjugates, copulas, and missing inverse CDFs.

## Overview

This module collects probability tools that go beyond the common single-variable distributions in the core module.

## Topics

- multivariate distributions
- information theory
- extreme value models
- Bayesian conjugates
- copulas
- inverse-CDF coverage gaps

## Notes

- Use this module when a probabilistic model needs more structure than the core `distributions` module provides.
- Keep an eye on domain assumptions when combining multivariate or copula-based models.
