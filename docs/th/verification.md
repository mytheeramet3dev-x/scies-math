# เอกสารอ้างอิง: การพิสูจน์และการส่งออกสู่ Lean 4 (`verification`)

โมดูล `verification` จัดเตรียมโครงสร้างบันทึกสายธารการอนุพัทธ์ทางคณิตศาสตร์ (Proof Provenance & Derivation Trees) และสะพานส่งออกโค้ดทฤษฎีบทอัตโนมัติไปยังระบบพิสูจน์เชิงโต้ตอบ Lean 4 และคลังทฤษฎีบท Mathlib

---

## 1. ต้นไม้การอนุพัทธ์ (Derivation Trees)

เพื่อตอบสนองมาตรฐานการตรวจสอบได้ทางวิทยาศาสตร์ การแปลงนิพจน์สัญลักษณ์สามารถบันทึกขั้นตอนเป็นกราฟระบุทิศทางแบบอวัฏจักร (Directed Acyclic Graph - DAG) โดยแต่ละโหนดจะบันทึก:
- **สมมติฐานเบื้องต้น (Premises)**: ตัวชี้ไปยังขั้นตอนก่อนหน้า
- **กฎทางพีชคณิตที่ใช้ (Rule / Justification)**: เช่น `AlgebraicSimplification`, `LinearCombination`, `Positivity`
- **ข้อสรุป (Conclusion)**: นิพจน์สัญลักษณ์ผลลัพธ์ [`Expr`]

---

## 2. สะพานส่งออกโค้ด Lean 4 / Mathlib4 (`lean_export`)

ทำหน้าที่แปลงข้อสรุปทางพีชคณิตให้อยู่ในรูปทฤษฎีบทของภาษา Lean 4 ที่ถูกต้องตามไวยากรณ์:

```rust
pub fn export_lean4_theorem(
    theorem_name: &str,
    hypotheses: &[(&str, &str)],
    conclusion: &str,
    proof_tactic: Option<&str>,
) -> String
```

### การระบุสถานะ Provenance
ทุกไฟล์ Lean 4 ที่ถูกสร้างขึ้นจะบรรจุหัวข้อกำกับสถานะอย่างชัดเจน เพื่อแจ้งเตือนว่าโค้ดนี้เป็นเพียงโครงร่างที่ยังต้องผ่านการ compile และตรวจสอบโดย Lean 4 Kernel:

```lean
/-!
  Generated by scies-math-th (v0.3.0)
  Status: Generated theorem skeleton (requires verification by Lean 4 kernel)
-/

import Mathlib

theorem pythagorean_identity (θ : ℝ) : (Real.sin θ) ^ 2 + (Real.cos θ) ^ 2 = 1 := by
  ring
```

## 3. ตัวอย่างการใช้งาน

```rust
use scies_math_th::symbolic::Expr;
use scies_math_th::verification::lean_export::{export_lean4_theorem, expr_to_lean};

fn main() {
    let x = Expr::sym("x");
    let poly = Expr::Add(vec![
        Expr::Pow(Box::new(x), Box::new(Expr::int(2))),
        Expr::int(4),
    ]);

    println!("ไวยากรณ์ Lean: {}", expr_to_lean(&poly)); // ((x ^ 2) + 4)

    let lean_code = export_lean4_theorem(
        "poly_strictly_positive",
        &[("x", "ℝ")],
        "x ^ 2 + 4 > 0",
        Some("positivity"),
    );

    println!("{}", lean_code);
}
```
